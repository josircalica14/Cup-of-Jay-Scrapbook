# cup of jay — hero

    npm install
    npm run dev

React 18 + Vite. No extra runtime dependencies. Styles live in `src/styles.css`,
animation logic in `src/hooks.js`.

## Your photo

`public/jay.jpg` is a pre-cropped version of your photo (600x460). To use a higher-res original, overwrite it with any image; it's cropped to a 300:230 frame via `.photo-img` in `styles.css` (tweak `object-position` to move the crop). If the file is missing, the illustration shows.
